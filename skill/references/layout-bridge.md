## 何时用本文件

用户的需求落在「信息排版」时：

- "用塞尔达风格做一份 PPT / 网页 PPT"
- "做一套塞尔达风的小红书图文 / 轮播图"
- "做一张塞尔达风的公众号头图 / 分享卡 / 海报"

> 注意区分：如果用户要的是**游戏界面**（HUD、库存、对话框、地图等），那是 `references/ui-cases.md` + `references/recipes.md` 的活，不是本文件。本文件只管"把信息排成版面"这件事。

## 第一步：前置检查（用户装了归藏 skill 吗）

先判断用户环境里有没有归藏的排版 skill（`guizang-ppt-skill` 或 `guizang-social-card-skill`）：

- **已安装** → 走下面的「互操作流程」（骨 + 皮，效果最好）
- **未安装 / 不确定** → 走「退化方案」（用本项目内建版式样板，见最后一节），并可顺带告诉用户："装上归藏排版 skill 能得到更专业的版式，安装方式见其 GitHub"

不要假设用户一定装了。先问或先探测，再决定走哪条路。

---

## 第二步：互操作流程（骨 + 皮）

1. **出骨架**：让归藏 skill 产出 **Style B 瑞士国际主义** 版式骨架（瑞士风是纯结构 + 单锚点色，最适合换皮）。
   - 杂志风（Style A）依赖特定字体 / 纸纹，换皮后会失真，**不主推**。
2. **换皮**：对产出的 HTML / CSS，按下方「Token 覆盖映射表」把视觉变量替换为塞尔达 token。
3. **叠装饰**：在 hero / 封面页叠一层希卡扫描线（`SheikahScanlines` 的视觉，或等效 CSS），强化塞尔达辨识度。
4. **守结构**：归藏的排版硬规则继续遵守（见「保留的排版硬规则」），换皮只动外观、不动版式结构。

---

## Token 覆盖映射表（本文件核心）

把归藏瑞士风的设计变量，逐一替换为塞尔达 token。**右侧 token 全部来自本项目 `references/design-tokens.md`，是原创映射。**

| 归藏瑞士风变量 | 它的默认值（如 IKB） | 覆盖为塞尔达 | 对应 token |
|---------------|--------------------|-------------|-----------|
| 锚点色 anchor | `#002FA7`（克莱因蓝） | 希卡蓝 `#3CD3FC` | `@sheikah-blue` |
| 页面背景 | 白 / 浅灰 | 深色 `#66645D` 或 `rgba(10,20,40,0.9)` | `@zelda-dark-bg` |
| 正文文字 | 近黑 `#111` | 暖白 `#E9E1D1` | `@text-color-main` |
| 次要文字 | 灰 | `rgba(233,225,209,0.6)` | 暖白带透明 |
| 标题字体 | Inter / Helvetica | `'Hylia Serif', 'Cinzel', serif` | `@font-title` |
| 正文字体 | Inter | `'Roboto', sans-serif` + **italic** | `@font-body` |
| 发丝线 / 分隔线 | 1px 纯色 | 1px `rgba(60,211,252,0.16)` | 希卡蓝低透明 |
| 强调 / 选中态 | 锚点色块 | 希卡蓝 + 辉光 `0 0 10px #4FC0FF, 0 1px 11px #0A8DD7` | `@glow-sheikah` |
| 大数字 / KPI 色 | 锚点色 | 希卡蓝 + 辉光，或暖白 `#E8E3D6` | `@sheikah-blue` |
| 装饰层 | 无 | 叠扫描线（scanline 纹理，opacity 0.06–0.1） | `SheikahScanlines` |
| 代码 / mono 字体 | 系统 mono | `'Roboto Mono', 'SF Mono', monospace` | `@font-mono` |

> 这些 token 的完整定义见 `references/design-tokens.md`。如需更精细的辉光 / 阴影 / 动效值，去那里查。

## 保留的排版硬规则（归藏的，继续遵守）

这些是**结构规则**，和视觉皮肤无关，换皮时原样保留：

- **网格锁定**：用归藏的 16 列网格，正文页从具名版式骨架里选，**不要自创页面结构**
- **越大越细**：大标题字号上去 → 字重必须下来（与塞尔达 Hylia Serif 标题用 400 normal 一致，天然契合）
- **中文大标题降一档**：避免中文占掉正文和图片空间
- **图文底对齐**：左文右图 / 左图右文场景，正文块与图片底部对齐，避开页脚翻页组件
- **图片进槽位**：图片必须放进模板预留的图片槽位，常见主图按 21:9 或 16:10
- **单锚点色**：塞尔达皮的唯一锚点色 = 希卡蓝。**不要**再引入第二个高饱和色（见下方反例）

## 正反示例

### 锚点色

```
✗ 把希卡蓝 #3CD3FC 和归藏原本的 IKB 蓝 #002FA7 同时出现在一张图里
  → 双锚点色，破坏瑞士风"单一锚点"的克制，也不像塞尔达

✓ 彻底用希卡蓝替换掉 IKB 蓝，全图只有一个高饱和色（希卡蓝）
  其余靠暖白 / 深色 / 发丝线撑层级
```

### 背景

```
✗ 保留归藏瑞士风的白色背景，只把文字改成希卡蓝
  → 这不是塞尔达（塞尔达铁律：禁止亮色 / 白色背景）

✓ 背景换成深色 #66645D 或 rgba(10,20,40,0.9)，hero 页叠扫描线
```

### 字体

```
✗ 保留 Inter 做标题
✓ 标题换 Hylia Serif，正文 Roboto italic（塞尔达铁律：正文 italic）
```

### 别动结构

```
✗ 觉得归藏版式不够"塞尔达"，自己重排网格 / 发明新版面
  → 丢掉了归藏排版能力，等于白接入

✓ 版式骨架原样用，只替换 token 和字体，叠装饰层
```

## 退化方案（用户没装归藏 skill）

本项目 demo 自带两个"塞尔达皮 + 瑞士骨"的成品页面，可直接作为内建版式样板参考（**这部分是本项目 100% 原创，无 license 顾虑**）：

| demo 路由 | 内容 | 可参考的版式 |
|-----------|------|-------------|
| `#/xhs` | 8 张小红书 3:4 组图 | 封面、大数字 KPI、编号特性列表、代码块 + CTA、组件展示墙、before/after 对比、分类网格、收尾页 |
| `#/poster` | 21:9 头图 / 1:1 分享卡 / 3:4 卖点页 | 横版 hero、方形分享卡、竖版 one-pager |

实现细节在 `demo/App.tsx`（`XhsPage` / `PosterPage` 组件）和 `demo/demo.css`（`.xhs-*` / `.poster-*` 类）。这些已经体现了 token 覆盖映射表的全部规则——大数字用 Hylia Serif + 希卡蓝辉光、发丝线分隔、单锚点色、深色背景叠扫描线。未装归藏 skill 时，直接照这两个页面的 DOM 结构和 CSS 排版即可。

> 这两个页面就是"骨 + 皮"已落地的证据：归藏的瑞士排版逻辑（网格 / 字号对比 / 发丝线 / 大数字）+ 塞尔达希卡视觉。
