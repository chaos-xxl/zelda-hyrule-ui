# 发版检查清单（Release Checklist）

> 每次 `npm publish` 前过一遍。**重点是防"文档/skill 落后于包"的版本漂移**——这个病已经犯过两次（AI_USAGE 标 0.1.0、skill 字体段停在 0.2.0 手动 @font-face），靠这份清单堵住。

## 发版前

- [ ] `package.json` version 已 bump（patch/minor/major 按 semver）
- [ ] `npx tsc --noEmit` 零报错
- [ ] `npm run build` 通过；抽查 `dist/`：
  - [ ] `dist/index.css` 含 `@font-face`，`dist/files/` 含 `HyliaSerif.*.ttf`
  - [ ] `dist/es/index.js` 首行 `"use client"`
  - [ ] `dist/types/index.d.ts` 存在
- [ ] `npm run build:demo` 通过

## 同步检查（防漂移，最容易忘）

- [ ] **skill 与包现状一致**：
  - [ ] `SKILL.md` 顶部 `Validated against zelda-hyrule-ui@X.Y.x` 已更新到当前大版本
  - [ ] `AI_USAGE.md` 顶部无过期版本号；React peer 要求与 `package.json` 一致
  - [ ] 若组件 props/枚举有增删 → 同步 `skill/references/props-quickref.md`、`components-full.md`、`FULL_COMPONENT_PLAN.md`
  - [ ] 若字体/打包方式有变 → 同步 `skill/references/design-tokens.md` 的字体加载段
- [ ] README 的组件数、bundle 体积、设计 token 表与代码一致
- [ ] GitHub 仓库 About 描述的组件数与 README 一致

## 发版

- [ ] `npm publish --auth-type=web`（网页认证，需作者本人操作）
- [ ] 从 npm 拉实包验证：`npm view zelda-hyrule-ui version` = 新版本；下载 tarball 抽查关键修复确实在产物里
- [ ] `git tag vX.Y.Z` + `git push origin vX.Y.Z`
- [ ] 建 GitHub Release（**中英双语** notes）

## 发版后

- [ ] 若是用户可感知的修复（如字体、Modal），考虑发一条小红书/社媒更新
